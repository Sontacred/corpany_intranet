# Corpany intranet README

## 1 - Le contexte et les objectifs du projet.

> "Tout seul on va plus vite,
ensemble, on va plus loin"

La société Corpany se spécialise dans le développement de solutions technologiques innovantes pour
le secteur de l'éducation. Elle offre une gamme de produits et services conçus pour améliorer
l'expérience d'apprentissage tant pour les enseignants que pour les étudiants.

Ce projet s’inscrit dans le cadre du développement d’un intranet pour l’entreprise Corpany, afin de centraliser les informations internes et de faciliter la communication et la collaboration entre les employés.

Un intranet est un réseau privé accessible uniquement aux membres d'une organisation, qui permet de partager des informations, des documents et de collaborer en interne.
